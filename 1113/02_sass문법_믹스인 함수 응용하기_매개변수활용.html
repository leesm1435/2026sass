매개변수를 사용하여 다양한 결과물을 구현할 수 있습니다.

    문법)
    mixin 믹스인명($매개변수...) {
      //재사용할 스타일 서식
    }
    @include 믹스인명(인수)

@mixin함수에 매개변수 기본값 설정하기

매개변수는 기본값을 가질 수 있습니다 @include에서 별도의 인수를 전달하지 않으면 기본값으로 사용이 됩니다.

    문법) 
    @mixin 믹스인명($매개변수 : 기본값) {
      //적용하고자 하는 css서식
    }
