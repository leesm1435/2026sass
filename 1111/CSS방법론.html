CSS방법론

CSS방법론은 대규묘 프로젝트 작업시 CSS코드베이스의 '유지 보수성', '재사용성', '확장성'을 향상시키기 위해 사용되는 일련의 규칙

이러한 방법론들은 'CSS코드의 구조를 개선'하고 개발자들이 '일관성있는 방식으로 스타일을 작성'할 수 있도록 할 수 있습니다.

1. 방법론의 종류

  1. OOCSS(Object Oriented CSS)

    CSS를 "객체"로 분해하여 스타일을 정의하는 방법론으로 CSS를 객체 지향 프로그래밍(OOP) 원리에 따라 구조화하여 재사용 가능한 컴포넌트를 만들고, 중복 코드를 줄이는 것을 목표로 합니다
    예) 버튼서식(로그인, 회원가입, 네이버 로그인, 카카오 로그인)

  2. SMACSS(Scalable and Modular Architecture for CSS)

    CSS 코드를 5가지 유형(기본, 레이아웃, 모듈, 상태, 테마)으로 나누어 규칙을 적용하고, 모듈화된 구조를 구축하여 확장성을 높이는 방법론입니다. 예)다크모드, 카드디자인...

  3. BEM(Block Element Modifier)

    UI를 독립적인 블록으로 분리하여, 블록 내의 요소(Element)와 수정자(Modifier))를 정의하여 '클래스 이름'을 규칙적으로 구성하는 방법론입니다.

2. 방법론의 장점, 단점

OOCSS
장점 : 코드 재사용성 증가, 중복 코드 감소, 유지보수 용이성
단점 : 배우기 여러율 수 있음, 복잡한 구조
SMACSS
장점 : 모듈화된 코드, 확장성이 용이하다, 코드 관리가 용이하다.
단점 : 규칙을 준수하기가 어려우며, 어버헤드 발생 가능성이 존재
BEM
장점 : 구조화된 코드, 클래스명 규칙을 정하여 사용, 유지보수의 용이성이 높다, 예측 가능한 코드
단점 : 긴 클래스명이 존재, 복잡한 구조를 가짐


CSS방법론은 프로젝트의 규모와 복잡성에 따라 적절하게 선택하여 적용하는 것이 중요하고, 각 방법론의 장,단점을 파악하여 팀의 개발 환경에 적용한다. 한가지 방법을 선택하여 적용하는것이 아니라 상황에 맞게, 프로젝트의 규모에 맞게 적절하게 혼합하여 사용한다.
