1. @for문

@for 키워드는 '스타일을 반복적'으로 출력하는데 사용됩니다.

javascript의 for문과 유사합니다.

    문법1 )
    through : 종료 만큼 반복
    @for $변수 from 시작 through 종료 {
      //반복할 내용
    }

    문법2 )
    to: 종료 전까지 반복
    @for $변수 from 시작 to 종료 {
      //반복할 내용
    }

$변수 => #{변수}

#변수는 코드 어디든지 변수 값을 사용할 수 있습니다.

적용 예) $img:unquote('./images/${img}');

h1 {background-image:url('./img/#{$img}');}

2. @while문

    @while 조건식 {
      //반복할 내용
    }

4. Lists와 Maps데이터

Lists와 Maps는 데이터를 여러 개 나열해서 담는 것을 의미한다.

자바스크립트에서 학습한 배열과 객체라고 이해하면 된다.

    let array = new Array(값1, 값2, 값3, 값4...);
    let fruits = ['사과', '배', '수박', '감', '복숭아'];

    1. Lists 문법
    작성법)
    $변수명 : 값1, 값2, 값3, 값4....;
    $변수명 : (값1, 값2, 값3, 값4...);
    $변수명 : 값1 값2 값3;
    
    2. map문법
    작성법)
    $변수명 : ('키명':값, '키명':값, '키명':값);
    Lists와는 다르게 괄호를 반드시 써야 함.
