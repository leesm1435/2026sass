2. @if문법

자바스크립트의 if문과 비슷하게 사용

@else를 붙여 false일 경우 실행하고, 다중 if문도 실행할 수 있습니다.

    문법)
    @if(조건) {
      //참일 경우 표현식
    }

    @if(조건) {
      //참일 경우 표현식
    } @else {
      //거짓일 경우 표현식
    }

    @if(조건1) {
      //조건1이 참일 경우 표현식
    } @else if (조건2) {
      //조건2가 참일 경우 표현식
    } @else {
      //위 조건식 모두 거짓일 경우 표현식
    }
